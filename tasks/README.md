# Tasks

## Workflow

```text
Backlog → Active → Implementation → Review → Testing → Completed → Documentation
```

A task is completed only when implementation, tests, review findings, and required documentation are complete, and architectural decisions have been recorded as ADRs when necessary.

## Naming

`TASK-XXXX-short-title.md`

## Directories

- `backlog/` — planned work
- `active/` — currently being implemented
- `completed/` — finished work
