# Documentation

Documentation explains the system for humans and contributors.

- `concepts/` — domain and conceptual explanations
- `architecture/` — architecture explanations derived from accepted decisions
- `development/` — local development and contribution workflow
- `operations/` — deployment, observability, and troubleshooting
- `reference/` — API/configuration/reference material

Do not use this directory as the source of architectural truth. Use `SPEC.md`, `ARCHITECTURE.md`, and ADRs for that.
